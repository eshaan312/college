## Vectors in the Plane
### VECTOR BASICS 

Scalar: a quantity with just a magnitude

Discover a new quantity, a magnitude and a direction. Instead of a number line it's on a plane.
It's called a vector

Vectors are equal if they have the same magnitude and the same direction.

A zero vector, 0 with a arrow above it, is at the origin and has 0 magnitude and no direction.

If vector starts at the origin and ends at (v1, v2) it is called a position vector and written <v1, v2>

Magnitude of a vector v is the square_root(v1^2, v2^2)

Direction (angle theta) theta = arctan (v2/v1)

If magnitude of vector is 1, its a unit vector

### VECTOR OPERATIONS

All vectors should have arrows on top, the components don't need to
u = <u1, u2>, v = <v1, v2>
k (scalar)

Addition: u + v = <u1 + v1, u2 + v2> -- (order doesn't matter)

Scalar Multiplication: k * u
if k = 2
2*u = u + u = <u1 * 2, u2 * 2>
so k * u = <u1 * k, u2 * k>
